# Archived Insights

> Status: archived
> Date: 2026-09-14
> Replaced by: current source, RFCs, ADRs, and active documentation

Historical maintainer execution records, including deep-insight reports,
round-based specifications, plans, task registers, and the insight ledger.

These records preserve how the system evolved and why hardening work was
undertaken. Treat current source code and active documentation as authoritative
when an archived record differs from present behavior.

## Navigation

- [Execution index](EXECUTION-INDEX.md) — consolidated round and work-unit
  map; the quickest way to locate a historical change.
- [Insight ledger](LEDGER.md) — findings marked landed, refuted, deferred, or
  duplicate; check this before reopening an old concern.
- [Deep-insight report](INSIGHT.md) — dated evidence and themes.
- [Baseline spec](SPEC.md) · [baseline plan](PLAN.md) — original hardening
  pass context.
- [Archive root](../README.md)

Round records use the `PLAN-*`, `SPEC-*`, and `TASK-*` prefixes. Later numbered
records (`R35`–`R143` and onward) are grouped by subject in the execution index;
the filename remains the stable identifier.

These files are maintainer history, not a public roadmap. To revive a finding,
open a current RFC or ADR and link back to the relevant archived evidence.
