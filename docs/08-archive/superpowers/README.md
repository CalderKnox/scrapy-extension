# Archived Superpowers Material

> Status: archived
> Date: 2026-09-14
> Replaced by: `00-rfcs/`, `01-adrs/`, and active design documentation

Retired implementation plans and design specifications from earlier project
work. The material is retained for historical context and migration research.

It is not an active task queue. New proposals belong in `00-rfcs/`, accepted
architectural decisions in `01-adrs/`, and current implementation guidance in
the relevant design, API, guide, or runbook directory.

## Navigation

Use the [archive root](../README.md) for the complete historical map. The
[plans/](plans/) subdirectory collects dated implementation plans and has its
own index. This directory intentionally has no “current status” index: plans
here describe earlier work and may be incomplete or superseded.

When citing one of these documents, include its date or round and link to the
replacement RFC, ADR, or design document when one exists. Do not edit a retired
plan to make it describe present behavior; add a dated note or update the
active document instead.
